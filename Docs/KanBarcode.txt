# บันทึกการพัฒนา

## รอบที่ 1 — สร้างเว็บหลัก
- สร้างไฟล์ `../index.html` เป็นเว็บ static แบบไม่ต้องติดตั้งหรือ build
- เปิดใช้งานด้วยการเปิดไฟล์ `index.html` โดยตรง หรือ deploy โฟลเดอร์นี้ขึ้น Vercel
- ข้อมูลรถและสถานะเอกสารตัวอย่างถูกเก็บใน localStorage ของเบราว์เซอร์
- ข้อมูลตัวอย่างสามารถเปลี่ยนเป็นข้อมูลจริงได้จากระบบนำเข้า Excel/SQL Server ในขั้นตอนเชื่อมต่อ backend ต่อไป

## รอบที่ 2 — เติมฝั่ง Vercel ให้ครบ (2026-08-27)
ตรวจสอบ `index.html` แล้วพบว่าหน้าจอครบทุกข้อกำหนดและ JavaScript ไม่มี syntax error
(element id ที่โค้ดเรียกใช้ 135 ตัว มีอยู่จริงในหน้า HTML ครบทุกตัว) แต่ยังขาดไฟล์ฝั่ง server
ที่หน้าจอ "เชื่อมต่อ SQL Server" เรียกใช้อยู่ จึงเพิ่มไฟล์ต่อไปนี้

- `api/sqlserver.js` — Vercel Serverless Function รับ POST ที่ /api/sqlserver
  - action "test" = ทดสอบเชื่อมต่อ คืนเวอร์ชัน SQL Server และชื่อ database
  - action "pull" = ดึงข้อมูลจาก view/table ที่ระบุ คืน {ok:true, rows:[...]} สูงสุด 5000 แถว
  - รองรับ server แบบ host\INSTANCE และ host,port
  - ตรวจชื่อ view ด้วย whitelist ก่อน query เพื่อกัน SQL injection
  - เปิด trustServerCertificate ให้ใช้กับ SQL Server ในองค์กรที่ใช้ self-signed cert ได้
  - error ทุกกรณีคืนเป็น JSON เสมอ เพื่อให้หน้าเว็บแสดงข้อความภาษาไทยได้ถูกต้อง
- `package.json` — ประกาศ dependency mssql ให้ Vercel ติดตั้งอัตโนมัติตอน deploy
  (ฝั่งหน้าเว็บยังไม่ต้อง build อะไรทั้งสิ้นเหมือนเดิม)
- `vercel.json` — ตั้ง memory 512MB / timeout 60 วินาที ให้ function และ rewrite / ไป index.html
- `.gitignore` และ `README.md` — สำหรับขั้นตอน deploy

### วิธี deploy
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub แล้วกด Import ใน Vercel หรือใช้คำสั่ง vercel CLI
2. Vercel จะติดตั้ง mssql และ deploy api/sqlserver.js ให้เอง ไม่ต้องตั้งค่าเพิ่ม
3. เข้าเว็บ เลือกเมนู "เอกสาร" แท็บ "เชื่อมต่อ SQL Server" กรอก server/database/user/password/view แล้วกดทดสอบ

### หมายเหตุเรื่อง NextJS
ข้อกำหนดระบุทั้ง "ไม่ต้องติดตั้งอะไรทั้งสิ้น no install no build step" และ "ใช้ Vercel + NextJS"
ซึ่งขัดกันเอง เพราะ NextJS ต้องมี build step เสมอ จึงเลือกทำเป็น static HTML + Vercel Serverless Function
ซึ่งได้ผลลัพธ์เหมือนกันทุกอย่างและ deploy บน Vercel ได้โดยไม่ต้อง build หน้าเว็บ
ถ้าต้องการเป็น NextJS จริง ๆ แจ้งได้ จะแปลงให้

### สิ่งที่ยังทำได้ต่อ
- ข้อมูลยังเก็บใน localStorage ของแต่ละเครื่อง ถ้าต้องการให้หลายเครื่องเห็นข้อมูลชุดเดียวกัน
  ต้องเพิ่ม database กลาง เช่น Vercel Postgres ซึ่งจะทำให้มี build/config เพิ่ม
- แผนที่แบบปักหมุดต้องใส่ Google Maps API Key ในหน้าตั้งค่า ถ้าไม่ใส่จะใช้แผนที่แบบฝัง embed แทน
